# XGif 프로젝트 리뷰·버그 수정·성능 개선

검토일: 2026-11-17. 대상: `F:\_NOAV\Xgif\XGif_v5`.

이 문서는 1차 검토 시점의 기록이다. 후속 수정·검증과 현재 남은 조건은
[출시 후보 검증 기록](RELEASE_HARDENING_2026-11-17.md)을 기준으로 한다.

## 범위와 판정

Git 추적 Python 파일 165개의 구조와 테스트 구성을 확인하고, `core`, `cli`,
`editor`, `ui`, `BootStrapper`의 녹화·저장·편집·설치 경로를 집중 검토했다.
전체 운영 코드와 테스트에는 Ruff 및 Python 컴파일 검사를 적용했다.
`build`, `dist`, 가상환경, 이전 작업 백업은 코드 수정 대상에서 제외했다.
모든 파일의 모든 실행 분기를 검증한 것은 아니다.

독립 코드 리뷰와 아키텍처 리뷰에서 찾은 재현 가능한 주요 결함을 수정했다.
새 패키지는 추가하지 않았으며 사용자 설정·설치본·배포 바이너리는 변경하지 않았다.
빌드 배포 승인이나 모든 환경에서의 무결함 판정을 의미하지 않는다.

최종 독립 코드 리뷰: **COMMENT, 검토 범위 내 미해결 차단 결함 없음**.
최종 아키텍처 판정: **WATCH**. 아래 메모리·취소 응답·장치 검증 한계가 남는다.

## 성능 측정

공유 툴바 미리보기는 현재 프레임만 갱신하도록 변경했다. 적용 및 취소는 기존 대상
선택 계약을 유지하며, 현재 프레임을 바꾼 뒤 적용/취소하는 경우도 검증했다.

측정 조건: 80장, 1280×720 RGB, 단순 이미지 copy processor, 5회 중앙값.
다른 모듈의 병렬 테스트·장치 상태에 따라 수치는 달라질 수 있다.

| 대상 모드 | 변경 전 | 변경 후 |
|---|---:|---:|
| ALL | 172.589ms | 2.025ms |
| SELECTED | 181.036ms | 2.496ms |
| CURRENT | 157.710ms | 3.549ms |

한 번의 미리보기 이미지 대입/복사는 **80회 → 1회**로 줄었다.
이는 해당 helper 측정이며 앱 전체 FPS나 CPU 사용량 개선치가 아니다.
이미지를 처음 여는 시점의 전체 snapshot 비용은 별도로 남아 있다.

비디오 가져오기는 원본 길이에 비례하던 Python sample-index 집합을 제거했다.
100만 초/2,400만 원본 프레임 메타데이터에서 출력 3장 제한 mock 측정은
Python peak allocation 81,173 bytes였다. 실제 FFmpeg의 내부 중간 프레임 디코딩
비용이나 전체 프로세스 RSS 측정은 아니다.

실제 FFmpeg 영상 검증: 2초 24fps 입력→20장/2,000ms,
5fps 입력→10장/2,000ms, 3장 제한→3장/2,000ms,
0.5~1.5초 구간→10장/1,000ms. 회전 영상도 별도로 검증했다.

편집기 저장 snapshot 복사는 GUI 스레드에서 worker로 이동했다.
저장 전 미리보기 타이머를 정지·반영하고 지연된 resize 콜백의 저장 중 변경을 차단한다.
snapshot 자체의 추가 CPU·메모리 비용을 제거한 것은 아니다.

## 남은 위험과 검증 한계

- 대용량 편집기 재생의 decoded 이미지 상주량, 효과 활성화 시 전체 snapshot,
  저장·Undo 복사에 대한 강제 메모리 상한은 보장하지 않는다. `FrameStore`는 현재
  실사용 경로에 연결되지 않으며 연결 전 디스크 저장 실패 시 보존 계약을 보완해야 한다.
- 비디오 불러오기 UI 취소 응답과 FFmpeg raw read 중 중단은 추가 개선 여지가 있다.
- 설치 교체는 두 번의 rename을 사용한다. 프로세스 강제 종료 시 자동 복구를
  보장하지 않으며, 복원 실패 시 남기는 staging backup을 복구에 사용할 수 있다.
- 오디오 혼합 실패 시 음성 없는 비디오로 저장하며 경고한다. 오디오 장치의
  callback 경계와 하드웨어 AV 동기는 이번 테스트만으로 보장할 수 없다.
- 기존 suite의 짧은 캡처·wx 위젯 테스트는 실행했으나, 장시간 화면/마이크 녹화,
  GPU별 인코더, 대화형 전체 GUI 시나리오, 다운로드/실제 설치, PyInstaller 재빌드는
  수행하지 않았다. 별도 정적 타입 검사기는 설치되어 있지 않아 실행하지 않았다.
